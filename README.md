# Расчет ресурсов инфраструктуры Kubernetes
В данном документе представлен расчет необходимых вычислительных ресурсов для развертывания приложения, состоящего из фронтенда, бекенда, базы данных и системы кеширования.

## 1. Требуемые ресурсы для планируемой инфраструктуры
Ниже приведен расчет суммарного потребления CPU и RAM всеми компонентами системы на основе заданных параметров.

| Компонент | Кол-во реплик | CPU на 1 шт | RAM на 1 шт | Итого CPU | Итого RAM |
| :--- | :---: | :---: | :---: | :---: | :---: |
| **База данных** (HA) | 3 | 1 core | 4 GB | 3 cores | 12 GB |
| **Кеш** (HA) | 3 | 1 core | 4 GB | 3 cores | 12 GB |
| **Фронтенд** | 5 | 0.2 core | 50 MB | 1 core | 0.25 GB |
| **Бекенд** | 10 | 1 core | 600 MB | 10 cores | 6 GB |
| **ИТОГО** | | | | **17 cores** | **30.25 GB** |

---

## 2. Выбор типа нод и учет системных ресурсов
Для обеспечения стабильной работы Kubernetes необходимо учитывать ресурсы, которые потребляют сама ОС, сервисы K8S и системные поды.

Для выбранного размера нод заложен резерв:
* **CPU:** ~10% на системные нужды.
* **RAM:** ~15% на системные нужды.

**Выбранный тип ноды:**
* **CPU:** 8 vCPU
* **RAM:** 32 GB

**Доступные ресурсы на одной ноде (после вычета системных):**
* **CPU:** ~7.2 cores
* **RAM:** ~27.2 GB

---

## 3. Расчет количества нод с учетом отказоустойчивости
Согласно правилам, инфраструктура должна выдерживать выход из строя как минимум одной ноды. Это означает, что суммарная нагрузка приложения ($17$ cores / $30.25$ GB) должна полностью умещаться на оставшихся $(N-1)$ нодах.

* **Если 3 ноды:**
  При падении одной остается 2 ноды.
  Доступно ресурсов: 7.2 cores * 2 нод = 14.4 cores.
  *Результат:* **Недостаточно** (требуется 17 cores).
* **Если 4 ноды:**
  При падении одной остается 3 ноды.
  Доступно ресурсов: 7.2 cores * 3 нод = 21.6 cores и 27.2 GB * 3 ноды = 81.6 GB RAM.
  *Результат:* **То что нужно** (21.6 cores > 17 cores и 81.6 GB RAM > 30.25 GB RAM).

---

## 4. Итоговая конфигурация
| Параметр | Значение |
| :--- | :--- |
| **Общее количество нод** | **4** |
| **Тип ноды (CPU/RAM)** | **8 vCPU / 32 GB** |
| **Отказоустойчивость** | Обеспечена моделью **N+1**. При выходе из строя одной ноды нагрузка распределяется между оставшимися без дефицита CPU/RAM. |
